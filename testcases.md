# Casos de prueba Translog (solo vocabulario existente en DB.pl)

## Sintagmas nominales

**Español → Inglés**
- Entrada: `el gato grande`  
  Traducción: `the big cat`

- Entrada: `gato grande`  
  Traducción: `big cat`

- Entrada: `el perro`  
  Traducción: `the dog`

**Inglés → Español**
- Entrada: `the big cat`  
  Traducción: `el gato grande`

- Entrada: `big cat`  
  Traducción: `gato grande`

---

## Oraciones SV (sujeto + verbo)

**Español → Inglés**
- Entrada: `el perro dormir`  
  Traducción: `the dog sleep`

- Entrada: `gato correr`  
  Traducción: `cat run`

**Inglés → Español**
- Entrada: `the dog sleep`  
  Traducción: `el perro dormir`

---

## Oraciones SVO (sujeto + verbo + objeto)

**Español → Inglés**
- Entrada: `el gato comer pez`  
  Traducción: `the cat eat fish`

- Entrada: `perro beber agua`  
  Traducción: `dog drink water`

**Inglés → Español**
- Entrada: `the cat eat fish`  
  Traducción: `el gato comer pez`

---

## Oraciones con estructuras complejas

**Español → Inglés**
- Entrada: `el perro dar gato comida`  
  Traducción: `the dog give cat food`

- Entrada: `el perro llamar gato amigo`  
  Traducción: `the dog call cat friend`
